# 🌍 Marhaba – Mobile Tourist Guide App
## 📌 Project Overview
Marhaba is a mobile tourism application designed to help travelers discover, plan, and organize their visits to tourist attractions in Morocco.
The app acts as a digital travel companion, offering personalized recommendations, interactive maps, and an intuitive user experience.

## 🎯 Objectives
The main goal of Marhaba is to:
 - Simplify travel planning for tourists
 - Provide easy access to tourist attractions
 - Offer an interactive and personalized experience
 - Integrate geolocation and mapping services

## 🚀 Key Features
### 🔐 Authentication
 - User registration and login (Email & Google)
 - Secure authentication with Firebase

###🏙️ Discover Destinations
 - Browse cities and tourist attractions
 - View attraction details (description, rating, price, schedule)

###❤️ Wishlist
 - Save favorite attractions
 - Build a personal travel list

###🔍 Search & Categories
 - Search attractions by name
 - Filter by categories (Beach, Mountain, Cultural, etc.)

###🗺️ Google Maps Integration
 - View attractions on interactive maps
 - Locate places easily with GPS

###👤 Profile Management
 - Upload and update profile picture
 - Personalized user experience
